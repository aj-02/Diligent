* The following example shows how to add a field to the list of selected fields for EKPO
    DATA: lv_selectedfield LIKE LINE OF o_poitemselectedfields.

    lv_selectedfield = 'KUNNR'.
    READ TABLE o_poitemselectedfields TRANSPORTING NO FIELDS
      WITH KEY table_line = lv_selectedfield.
    IF sy-subrc <> 0.

      APPEND lv_selectedfield TO o_poitemselectedfields.
    ENDIF.

* The following example shows how to remove the hardcoded restriction for the selection from table EKKO
    READ TABLE O_POITEMSELECTOPTIONS TRANSPORTING NO FIELDS
      WITH KEY fieldname = 'KNTTP' SIGN = 'E' OPTION = 'EQ' LOW = 'U' HIGH = ' '.
    IF sy-subrc = 0.
      DELETE O_POITEMSELECTOPTIONS INDEX sy-tabix.
    ENDIF.
