# SAP KBA 3049624 — Missing fields in Asset Accounting reporting Fiori Apps

Component: **FI-FIO-AA** (Financial Accounting > Fiori UI for Financial Accounting > Fiori UI for Asset Accounting)
Version: 8 · Released On: 21.01.2025 · Type: SAP Knowledge Base Article

## Symptom

When checking Fiori App "Asset History Sheet" (F1615) or "Asset Balances" (F1617), not all
fields from transactions AR02/AR01 are available as dimensions in Fiori Apps.

## Environment

- SAP Fiori for SAP S/4HANA
- SAP Fiori for SAP S/4HANA Finance

## Reproducing the Issue

1. Execute reporting Fiori Apps ("Asset History Sheet" / "Asset Balances")
2. You want report to show a required field
3. Field is not listed as 'Dimension'

## Cause

Not all fields from tables **ANLA** and **ANLZ** are part of standard SAP Fiori applications
"Asset History Sheet" or "Asset Balances" because of performance and practical usage.
Standard applications are providing the most suitable and frequently used or needed fields.

## Resolution

Fiori Apps are working as designed. Fiori app Asset History Sheet is based on cube view
`I_AssetHistorySheetCube`. This view is released to customers. It means any customer can
build their own query on top of this cube view. The association `_FixedAsset` is exposed, so
it is possible to add properties from `I_FixedAsset` in a custom query. This CDS View
`I_FixedAsset` have reference extension view **`E_FixedAsset`**. Using this Extension View,
you can add any field contained in table **ANLU**.

If, nevertheless there is a specific requirement to display an additional field (not
contained in table ANLU), an experience Fiori Developer can be contacted for creating custom
Fiori app based on Custom Analytical Query and standard CDS views according to any business
needs.

**1. For System Versions S/4 HANA 1809 FPS03 and SAP S/4 HANA 1909 FPS01 and above, or after
SAP Note 2834107 implementation, the following queries are delivered:**

| Fiori App | CDS View (Analytical Query) | BW Cube (Cube View) |
|---|---|---|
| Asset History Sheet | `C_FixedAssetHistorySheet` | `I_FixedAssetAHSValueCube` |
| Asset Balances | `C_FixedAssetBalance` | `I_FixedAssetValueCube` |

These queries are build using following consumption CDS views and BW cubes:
- Asset History Sheet: `2CCFASSETHISTSHEET`
- Asset Balances: `2CCFASSETBAL`

**2. For System Versions S/4 HANA 1809 FPS02 and lower, the following queries are delivered:**

| Fiori App | CDS View (Analytical Query) | BW Cube (Cube View) |
|---|---|---|
| Asset History Sheet | `C_AssetHistorySheet` | `I_AssetHistorySheetCube` |
| Asset Balances | `C_AssetBalance` | `I_AssetBalanceCube` |

These queries are build using following consumption CDS views and BW cubes:
- Asset History Sheet: `2CCFASTHISTSHEET`
- Asset Balances: `2CCFASTBALANCE`
