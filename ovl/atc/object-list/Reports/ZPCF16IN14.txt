** Form 12BB
*-- Email Attachment folder path
*&---------------------------------------------------------------------*
*&      Form  GET_FOLDER_NAME
*&---------------------------------------------------------------------*
*       text
*----------------------------------------------------------------------*
*      -->P_LAYOUT  text
*      -->P_LANGU  text
*----------------------------------------------------------------------*
FORM get_folder_name CHANGING folpath.
  DATA: patt       TYPE string VALUE `\`,
        text       TYPE string,
        result_tab TYPE match_result_tab,
        len        TYPE i.

  FIELD-SYMBOLS <match> LIKE LINE OF result_tab.

  text = folpath.


  FIND ALL OCCURRENCES OF patt IN
       folpath
       RESULTS result_tab.

  SORT result_tab DESCENDING BY offset.
  READ TABLE result_tab INDEX 1 ASSIGNING <match>.

  IF ( sy-subrc EQ 0 ).
    i = <match>-offset + 1.
  ENDIF.

  folpath = text+0(i).

ENDFORM.                               " GET_FOLDER_NAME
