WHY THIS SIZE - DO NOT JUST MAKE IT BIGGER
------------------------------------------
The template export writes at most as many COLUMNS as the RawData name declares,
and it also appears to work to a total budget of roughly 90,000 cells, trimming
columns to fit the declared row count. Rows are not capped - the export extends
them past the declaration.

Observed:
  74 cols x  778 rows =  57,572 cells  ->  74 columns written (1 short of 75)
 104 cols x 5000 rows = 520,000 cells  ->  18 columns written (90,000/5000 = 18)
  75 cols x 1000 rows =  75,000 cells  ->  expected 75 columns

Rule of thumb: declared columns must be >= the number the report produces
(2 + number of ventures), and declared columns x declared rows should stay
under about 90,000. Widening the range without watching the row count is what
cut the output to 16 ventures on 27/08/2026.

If a 74th venture is added, extend RawData one column to BX and keep rows at
1000 (76 x 1000 = 76,000, still within budget).

To see it in Excel: Formulas -> Name Manager (Ctrl+F3), RawData and Header rows.
